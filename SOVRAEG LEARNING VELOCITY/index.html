About this edition

The pages are edited web-publication adaptations of the three prompt–response exchanges in this thread. Original user prompts are preserved, while the assistant responses are reorganized into readable, interactive chapters rather than claimed to be verbatim transcripts. All chart values and financial examples are hypothetical.

Open index.html to browse locally, or publish this folder as a static GitHub Pages site. All visuals, CSS and JavaScript are included locally; no CDN, build tools or API keys are required.
