## Fidelity and limitations

The four prompt/response pairs preserve recovered wording. Rich component layout has been translated into Markdown and portable HTML. Interactive tools are reconstructions from visible labels, data, selections, and formulas; stated assumptions remain visible in the tools. JavaScript does not execute inside the single Obsidian note, so it includes the tools' source and data for archival completeness.

Three external karate thumbnails could not be downloaded because browser permissions blocked them. Their titles and original links are retained. The local charts and interactive components work offline.

The original export checked 887 passages and 41 equations. See [validation](source/validation.txt), [provenance](README.txt), and [checksums](source/checksums.sha256).
